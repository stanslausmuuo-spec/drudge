# Legal & Regulatory Compliance Statement — Project Jarvis

**Compliance Framework:** GDPR, CCPA, and AI Governance

## 1. Data Protection & GDPR Compliance
- **Right to Erasure (Article 17 GDPR):** Because all conversational memory and session history are stored locally on your device (`localStorage` and local JSON/Mem0 stores), you retain absolute control and can delete all stored data instantly via the "clear" button in the application UI or by removing local storage.
- **Data Minimization (Article 5(1)(c) GDPR):** The system processes only data strictly necessary for voice and vision interaction.

## 2. AI Governance & Transparency
- **Model Attribution:** Users are explicitly informed of active models (e.g., Llama 3.1, GPT-4o, Claude 3.5, Gemini 2.0) via the UI indicator.
- **Human-in-the-Loop:** System actions (such as volume adjustment, file reading, and web search) require user intent or voice command confirmation, ensuring human oversight over agentic operations.
